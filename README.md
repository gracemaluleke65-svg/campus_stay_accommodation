# 🏠 Campus Stay Accommodation

A full-stack web application for finding and booking student accommodation across South African campuses. Built with **Flask**, **PostgreSQL**, and **Stripe** payments.

---

## ✨ Features

- 🔍 **Search & Filter** — Find accommodation by location, price range, and room type
- 💳 **Stripe Payments** — Secure online booking payments
- ⭐ **Reviews & Ratings** — Leave reviews after booking
- ❤️ **Favorites** — Save accommodations to your wishlist
- 🏠 **Admin Dashboard** — Manage accommodations, users, and bookings
- 📱 **Responsive Design** — Works on mobile, tablet, and desktop

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| **Backend** | Python 3.11, Flask 3.0 |
| **Database** | PostgreSQL (Neon) |
| **ORM** | Flask-SQLAlchemy |
| **Auth** | Flask-Login, Werkzeug |
| **Forms** | Flask-WTF, WTForms |
| **Payments** | Stripe Checkout |
| **Images** | Cloudinary |
| **Frontend** | Bootstrap 5, Jinja2 Templates |
| **Deployment** | Vercel (Serverless) |
